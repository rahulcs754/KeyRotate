CLI · Runs locally · Free and open source

Breached? Rotate the right keys, and prove the old ones are dead.

When a platform you deploy on gets breached, "rotate your secrets" is the advice. KeyRotate finds every secret you store there, tells you who issued each one, gives you a checklist in priority order, and checks each old key now fails.

Quick start View on GitHub

Three commands

1scan

Reads env var names from .env* files, GitHub Actions, Vercel, GitHub secrets and Railway. Shows where every copy lives.

2plan

Maps each one to its issuer (OpenAI, Anthropic, AWS, Stripe, your DB...) and writes a Markdown checklist, high priority first, with rotate links and steps.

3verify

Calls each issuer's read-only auth check with the old key. Fails your script if any old key still works.

Built for the breach day

Only what was exposed

--breached vercel keeps only secrets stored on that platform.

Every copy

One name in .env.local, Vercel and a workflow? You see all three, and a warning if their values differ.

Public var traps

A live secret key inside NEXT_PUBLIC_ is raised to high priority, with a fix.

Values stay local

Remote sources are read as names only. Values are masked and only sent to the issuer's own API.

Quick start

  1. In your app folder (Node 20+): 
    npx github:rahulcs754/KeyRotate scan
  2. Write the checklist for the breached platform: 
    VERCEL_TOKEN=... npx github:rahulcs754/KeyRotate plan \
  --vercel my-app --breached vercel --out ROTATION.md
  3. Back up the old values, rotate, then prove the old keys are dead: 
    cp .env.local /tmp/old.env
# rotate keys, update .env.local and your platforms
npx github:rahulcs754/KeyRotate verify --old /tmp/old.env --new .env.local

Issuers

Auto verify: OpenAI, Anthropic, Stripe, GitHub, npm, Vercel, Cloudflare, Clerk, Google API keys, Groq, Mistral, Hugging Face, Replicate, Pinecone, Slack, SendGrid.

Guided manual check: AWS, databases (Postgres, MySQL, Mongo, Redis, Upstash, Neon), Supabase, Razorpay, Railway, Twilio, Sentry, Resend, OpenRouter, and your own app secrets like NEXTAUTH_SECRET.
